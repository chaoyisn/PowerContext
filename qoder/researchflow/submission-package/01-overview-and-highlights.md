# 01 · 项目介绍与亮点

**ResearchFlow** — 基于 seekdb 与 PowerContext 的科研知识与任务连续性助手。
OceanBase × Qoder 2026 数据库比赛 · Qoder 赛道参赛作品，代码位于
`qoder/researchflow/`（分支 `2026-competition-ecosystem`）。
在线展示站：<https://researchflow-5esfsogn38f.qoder.zone>

---

## 1. 真实的科研痛点

| 痛点 | 具体表现 | 本项目的对应做法 |
| --- | --- | --- |
| AI 答案无法回查 | ChatPDF 类工具给出结论但点不到原文，页码经常对不上 | 每条引用可点开 **seekdb 中存储的该物理页原文**；页码用 PDF 物理页号（从 1 开始），空白页也保留页级身份 |
| 结论与资料混在一起 | 模型补的常识和文献里真写了的内容读不出来有什么区别 | 每条论断标注「资料直接支持 / 模型推断 / 尚无证据」，服务端逐条回查数据库校验 citation |
| 换会话就断片 | 重开一个对话要重新解释目标、已完成的工作和已确认的决策 | 仅凭 `project_id` 从 PowerContext 恢复，并生成确定性的「上次做到了哪里 / 接下来该做什么」续研简报 |
| 证据与记忆互相污染 | 把「上次我记得的东西」当作本轮的文献依据 | seekdb 管文献证据、PowerContext 管任务记忆，两条通道在 UI 与 API 里分别标注，**可独立断开验证**（T7/T8） |
| 语料里没有答案时硬编 | 编一个看起来合理的页码 | 证据门控 + `no_evidence`：不产生任何 citation（T3） |

## 2. 亮点

1. **真数据、真组件、无模拟。** seekdb v1.4.0.0（Docker，`127.0.0.1:2881`，`ik` 全文 + 384 维
   HNSW 余弦向量）与 PowerContext 1.4.1（`127.0.0.1:17429`）都是真实运行依赖；
   没有预置答案、没有 mock 层。断掉任何一个依赖，接口报真实错误而不是返回漂亮的结果（T8）。
2. **内容寻址的文档主键。** `doc_id = SHA-256(文件字节)`，同一文件重复上传自动去重；
   物理页 `page_id` 可由 `doc_id` 复算，因此引用在重建后仍然稳定。
3. **三模检索可并排对比。** `vector` / `fulltext` / `hybrid`（RRF `1/(rank_constant+rank)`，
   默认 60）同屏展示，并给出按 `chunk_id` 计算的重叠分析；每条结果带 `score_kind`、
   coverage、relevance 与稳定 chunk id。演示问题命中的 RRF 融合分 `0.0328`
   与文档里手写的期望值一致（可核对，不是巧合）。
4. **服务端 citation 校验（不是提示词承诺）。** 模型给出的每个引用都要回查 seekdb：
   不在检索结果里的、页码不存在的 → 剔除并上报 `invalid_citations`；失去引用的
   「资料直接支持」自动降级为「模型推断」。
5. **记忆写入永远是显式动作。** 一个项目 = 一个 Scope，`idempotency_key` 绑定；
   重复内容 `skipped_duplicates`、内容未变化不产生新快照；重启与重试安全（T4/T6）。
6. **证据分级诚实。** 未配置 LLM key 时进入明确标注的「仅检索模式」；
   PowerContext 默认全文索引对纯中文不友好，因此加了一层中文感知召回，
   并在响应里用 `search_backend_used` 明示这一条究竟是谁答的。
7. **可复现的验收。** 149 个自动化测试直接打真实依赖；T1–T9 端到端验收
   （含真实服务重启、真实断连）150 项校验全 PASS；另有一次全新 venv / 全新容器 /
   全新数据目录的评审旅程 20 步全过，跑完自动清理不影响同机其他赛题。

## 3. 规模与形态（实测）

| 维度 | 值 |
| --- | --- |

| 端到端验收 | T1–T9 全 PASS，150 项校验，报告与逐用例日志在 `verification/acceptance-run/` |

## 4. 与其它参赛作品的差异（一句话）

不是「又一个 ChatPDF」：它把**证据可回查**与**任务连续性**当成两个独立的存储系统来做，
并且把「断了会怎样」也做成可验收的用例。

## 5. 明确的边界（不夸大）

- 公开站点是展示版，**不连数据库、不可交互**；完整体验需本地按 `RUN.md` 启动。
- 后端只监听 `127.0.0.1:8787`，不对公网暴露：PowerContext 侧没有多用户鉴权，
  开放会让匿名用户互相读取文档与记忆。
- 全文检索依赖 `ik` 分析器；共享 seekdb 容器用 `rf_` / `rfacc_` 前缀与其他赛题隔离。
- 工作流提效数字（`09-usage-impact-sources.md`）是**脚本代理测量**，不是真实用户实测。
- 基准里未通过的项如实保留：B2 有 2 条「英文改写问中文原文」在默认阈值下被门控拦下；
  W1 有 1 条排序不符预期。
